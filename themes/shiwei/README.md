# 视维蓝企业模板（shiwei）

仿 `http://temp-shiweikeji/` 的蓝白企业站版式，接入 `tempqiyecms` 的栏目、文章、单页与站点设置，一套模板同时适配 PC 与手机。

## 启用

后台「模板中心」选择 **视维蓝企业模板** 启用；也可直接把 `tp_setting` 中 `theme` 设为 `shiwei`。

## 文件

| 文件 | 用途 |
| --- | --- |
| `_top.php` / `_bottom.php` | 全站页头、移动菜单、页脚、公共 JS |
| `index.php` | 首页：轮播、解决方案、服务、产品横滑、CTA |
| `list.php` | 栏目页：产品网格 / 方案圆图列表 / 新闻卡片 / 服务图文 |
| `article.php` | 文章页：产品详情双栏、普通文章详情、上下篇 |
| `page.php` | 单页：关于我们、企业文化、联系页三卡 + 路线块 |
| `style.css` | 全站样式与响应式断点 |
| `theme.json` | 模板元信息 |
| `screenshot.png` | 后台模板缩略图 |

## 数据对应

- 导航：`关于我们` → `page.about`，`解决方案 / 产品中心 / 服务支持 / 新闻中心` → 对应栏目，`联系我们` → `page.contact`。
- 首页轮播：优先 `plugin_filter('home_slides')`（轮播插件），无插件时回退 `/uploads/factory.jpg`、`line.jpg`、`team.jpg`。
- 解决方案四卡：`solution` 栏目文章，不足 4 条自动补「非标定制」。
- 服务四卡：系统集成 / 网络部署 / 产线运维 / 技术支持，链到 `service` 栏目。
- 产品横滑：`product` 栏目及子栏目文章，取 6 条。
- 关于页图片：页头 `team.jpg`，正文上方 `factory.jpg`。
- 联系页：电话、邮箱、地址取自站点设置，`site_phone2` 可选填座机，未填显示 `010-1111111`。

## 替换图片

模板只引用站内 `/uploads/` 图片，不依赖源站素材。需要换图时上传到后台媒体库并替换对应文章封面/单页图片即可。

## 响应式

- `>1120px`：桌面完整版，1200px 容器，四卡方案、四圆服务、三列产品。
- `≤1120px`：导航与搜索收紧。
- `≤980px`：隐藏桌面导航，显示汉堡菜单，方案/服务两列。
- `≤800px`：内页侧栏单列；文章/单页隐藏侧栏，正文优先。
- `≤620px`：单列方案、两列产品、页脚两列，首屏文字缩小。
