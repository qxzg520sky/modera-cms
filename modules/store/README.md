# modules/store

主仓库默认只放一个模块包：

- `plugin-example.zip`：示例插件，安装后用于开发参考。

其余插件和模板不再随主程序打包，统一放在独立的 `market` 下载分支：

- 模块目录：<https://gitee.com/51iqx/modera-cms/raw/market/catalog.json>
- 单独下载与安装说明：<https://gitee.com/51iqx/modera-cms/blob/market/README.md>

需要后台在线安装时，先下载 `plugin-market.zip`，在“模块中心”上传安装“应用市场”插件，再从应用市场获取其他模块。
